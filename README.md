# pdf-nmf
non-negativ matrix factorization for pair-distribution function analysis.

The code is still work-in-progess. 

Please refer to PDFitc.org for a published and peer-reviewed version:
Thatcher, Z., Liu, C.-H., Yang, L., McBride, B. C., Thinh Tran, G., Wustrow, A., Karlsen, M. A., Neilson, J. R., Ravnsbaek, D. B. & Billinge, S. J. L. (2022). Acta Cryst. A78, 242-248.

It is based on this paper:

Liu, C.-H., Wright, C. J., Gu, R., Bandi, S., Wustrow, A., Todd, P. K., O'Nolan, D., Beauvais, M. L., Neilson, J. R., Chupas, P. J., Chapman, K. W. & Billinge, S. J. L. (2021). J. Appl. Cryst. 54, 768-775.
